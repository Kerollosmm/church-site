# Project Brief — البوابة الرعوية لكنيسة القديسين مكسيموس ودوماديوس والأنبا موسى الأسود

## المهمة
بوابة رعوية عامة فائقة السرعة بصفر مصادقة (Zero-Auth) توفر القداسات، دليل العيادات الخيرية الـ 14، البث المباشر، والحجز العام لقاعة العزاء — بطابع قبطي أرثوذكسي أصيل وRTL أولاً.

## الثابت المعماري INV-01 (غير قابل للتفاوض)
1. لا مصادقة مطلوبة لأي دليل أو جدول عام.
2. لا تُخزن أو تُعالج أبداً بيانات اعترافات أو ماليّة رعاية داخلية في هذه البوابة.
3. أي مقترح يمزج ERP الداخلي بالبوابة يُفرز `wontfix`.
