1. DIRECTION & LOCALIZATION (dir="rtl")
--------------------------------------------------------------------------------
- Root HTML in apps/web/src/app/layout.tsx:
  * Default document direction: dir="rtl", lang="ar"
  * Dynamic locale adaptation: switches to dir="ltr", lang="en" when English locale cookie is set.
- Admin layout in apps/admin/src/app/(protected)/layout.tsx:
  * Applies dir={LOCALE_DIRECTION[locale]} and lang={locale} with data-admin-locale attribute.
- All margin/padding utilities use logical start/end properties (start-0, ps-*, pe-*) to ensure
  flawless RTL alignment across Arabic and English surfaces.

--------------------------------------------------------------------------------
2. ARIA ROLES & ACCESSIBLE SEMANTICS
--------------------------------------------------------------------------------
- Desktop Navigation (HeaderClient.tsx):
  * Primary navigation landmarks: <nav aria-label="التنقل الرئيسي">
  * Dropdown disclosure triggers:
    - aria-haspopup="true"
    - aria-expanded={isOpen}
    - aria-controls={`nav-menu-${item.id}`}
  * Dropdown container:
    - role="menu"
    - aria-labelledby={`nav-trigger-${item.id}`}
    - aria-orientation="vertical"
  * Dropdown links: role="menuitem"
- Mobile Navigation Drawer:
  * Drawer container: role="dialog", aria-modal="true", aria-label="قائمة التنقل الجوال"
  * Drawer hamburger button:
    - aria-label={mobileMenuOpen ? "إغلاق القائمة" : "فتح القائمة"}
    - aria-expanded={mobileMenuOpen}
- Status & Loading States:
  * Skeleton components: role="status", aria-label="جاري التحميل..."
  * Admin tables: role="status" on empty feedback, accessible th/td scope attributes.

--------------------------------------------------------------------------------
3. FOCUS RINGS & KEYBOARD NAVIGATION
--------------------------------------------------------------------------------
- Clear, high-contrast visual focus rings:
  * focus-visible:outline-2 focus-visible:outline-copticNavy focus-visible:outline-offset-2
  * Present on all navigation buttons, links, search filters, and modal close buttons.
- Keyboard interaction model in HeaderClient.tsx:
  * Enter / Space: toggles open/close state of focused dropdown menu.
  * ArrowDown: opens the dropdown and focuses child items.
  * Escape: immediately collapses open dropdown and returns focus to trigger.
- Touch Target Heights:
  * Mobile drawer links enforce touch targets >= 44px min-height (min-h-[44px]).
  * Fast-action header buttons enforce min-h-[36px] on tablet, >= 44px on mobile drawer.
